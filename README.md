# DES_test

## 설치
* pip install -r requirements.txt

## 실행
* python app.py
* http://127.0.0.1:5000/ 에 접속

## test 방법
* page 1: DES 암호화 실험 (16진수)
  * 평문과 키에 16진수 16자리 수를 각각 입력한 후 암호화 버튼을 누르면 DES암호화 결과가 아래 나타난다.
  * 복호화 버튼을 누르면 암호문의 복호화 결과가 나타난다.
 
* page 2: DES Round 1 계산 과정
  * 평문과 키에 16진수 16자리 수를 각각 입력한 후 계산하기 버튼을 누르면 DES round1의 각 단계의 계산 결과가 나타난다.
  * 최종결과에 나타난 16진수를 다시 평문에 붙여 넣고 계산하기 버튼을 다시 누르면 평문이 나타난다.

* page 3: 1의 보수 암호화 실험
  * 평문과 키에 16진수 16자리 수를 각각 입력한 후 암호화 버튼을 누르면 오른쪽에 평문과 키의 1의보수가 출력되고 아래쪽에는 암호화 결과들이 나타난다.

* page 4: DES 취약키 테스트
  * 화면에 나열된 취약키중 하나를 복사해서 키에 넣고 테스트 버튼을 누르면 평문을 이 키로 두 번 암호화한 결과를 볼 수 있다.

* page 5: DES 준취약키 테스트
  * 화면에 나열된 준취약키중 하나를 복사해서 키에 넣고 테스트 버튼을 누르면 붙여 넣은 키로 만든 암호문과 짝이되는 다른 키로 암호화한 결과가 나타난다.
